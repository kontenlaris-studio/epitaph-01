Famous Last Words: The Funniest Epitaph — one line, 74 characters: "Gone, but his unread emails remain. Please do not reply all to this stone."

Why it works: it reads like a real epitaph carved in stone — it addresses the passer-by directly — and the joke turns on the last five words, when the dead man files his final complaint about reply-all. The unread inbox is the one thing death could not clear.

## Run it

```sh
python3 main.py
```
